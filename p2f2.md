GOAL: Add a post-race "Race Review" tab. For a chosen race and driver it
(1) reconstructs the real race, (2) scans every pit decision for regret,
(3) runs Monte Carlo what-ifs of the form "pit N laps earlier/later, same
compounds", and (4) shows predicted-vs-actual tyre degradation.

RULES
- New files only (replay/, a new Streamlit page/tab file, docs/RACE_REVIEW.md).
  Allowed edits to existing files: register the tab in app.py, and edit README.md
  text only to label the existing backtest as "in-sample sanity check (13 of 15
  races were in the training data)". Do not touch engine/, pipeline/, ml/ or the
  production model.
- Do NOT use replay/offsets.py compound offsets (invalid: wrong sign).
  Compound-change what-ifs are out of scope.
- Never guess. If something is missing, write NOT FOUND and continue with the
  fallback below.

PHASE 0 - gates. Write all results to replay/GATES.md, then continue without
waiting.
 G1. Find the PIT/STAY_OUT thresholds in backtester.py, paste them, and show the
     git history of those constants (or say there is none).
 G2. Train a model with all Bahrain GPs removed (same settings as ml/trainer.py)
     -> models/loro_bahrain.joblib.
 G3. Degradation check on Bahrain 2023 with that model: for stints with >=12 clean
     green laps, pairs of laps 5 apart; actual vs predicted increments; compare MAE
     against a per-compound linear slope on tyre_age fitted on non-Bahrain data.
     Report MAE, bias, and the split by compound and by age bucket. DECISION RULE:
     if XGBoost MAE < linear MAE use XGBoost increments, else use the linear
     slopes; record which one.
 G4. Relative pit loss per stop = (driver's Time_s gain over the in-lap+out-lap
     window) minus (median over cars with no pit on those laps). Report median/IQR
     for neutralized vs green stops and list each stop.

PHASE 1 - what-if engine (replay/whatif.py). Use the delta formulation: the
counterfactual cumulative time = actual Time_s + cumulative delta, where delta
comes from (a) lap-time differences on laps whose tyre age or stint changes, and
(b) the pit-loss difference. Method:
 - Laps that reuse a real tyre age use the REAL lap time, with the pipeline's own
   fuel model used to remove and re-add the fuel effect for the new lap number
   (import it, do not edit it).
 - Laps beyond any real tyre age use the last real clean lap plus the G3-chosen
   increments.
 - Pit loss is sampled from the G4 relative pit-loss sample for this race, from
   the neutralized set if the new in-lap/out-lap falls in a neutralized window,
   otherwise from the green set. No hand-typed multipliers.
 - Noise: per-path stint-level random offset plus block-bootstrapped residuals
   from G3 (no independent per-lap Normal). Use common random numbers: the same
   seeds for the actual and counterfactual paths. 500+ paths.
 - Position at each lap = rank of the counterfactual cumulative time among
   rivals' ACTUAL cumulative times. State in the UI: "rivals held fixed, no
   traffic or reaction model".
 - Unit tests: shift 0 laps -> delta exactly 0 and positions unchanged; shifting
   +1 then comparing against -1 gives opposite-sign effects on the pit-loss
   term. Show test output.

PHASE 2 - regret scan + degradation view
 - For each real stop of the selected driver, evaluate shifts of -8..+8 laps
   (skip infeasible ones). Output: expected time delta, 90% interval, and P(final
   position improves) per shift, and a regret plot per stop. Label any shift
   whose interval contains zero as "not distinguishable from noise".
 - Degradation tab: predicted vs actual per stint, residual summary.

PHASE 3 - UI + honesty
 - Streamlit "Race Review" tab: race/driver selectors, replay table, regret plot,
   what-if slider, position distribution, degradation chart.
 - If the selected race was in the training set and no leave-out model exists,
   show a banner: "model saw this race: in-sample". Bahrain uses loro_bahrain.
 - docs/RACE_REVIEW.md: method, assumptions, limitations, and the G1-G4 numbers.

FINISH by printing replay/GATES.md and the unit test output.
