# Local Asset Folders

Store user-provided images here. Do not download images from the internet for this project.

Recommended names:

```text
assets/home/homepage.png
assets/home/homepage_hero.webp
assets/drivers/VER.png
assets/cars/red_bull_rb20.png
assets/tracks/bahrain.png
```

When a needed image is missing, ask the user for the local file.
